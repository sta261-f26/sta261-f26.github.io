Atomic vectors

Atomic vectors are one-dimensional objects, and are indexed with [ ]:

x <- c(0, 23, 98)
length(x)
[1] 3
x[1]
[1] 0
x[2]
[1] 23
x[1:2]
[1]  0 23
x[c(1, 3)]
[1]  0 98

Atomic vectors

Vectors can contain numbers, booleans, characters, etc:

x <- c(0, 1, 2)
x
[1] 0 1 2
typeof(x)
[1] "double"
x <- c("a", "b", "c")
x
[1] "a" "b" "c"
typeof(x)
[1] "character"

Rectangular data in R

In R, there are two main ways of storing rectangular data:

  • matrices
  • data frames

Matrices

A matrix generalizes a vector to two dimensions:

x <- matrix(c(1, 2, 3, 4, 5, 6), nrow=2)
x
     [,1] [,2] [,3]
[1,]    1    3    5
[2,]    2    4    6
  • Each row is an atomic vector
  • Each column is an atomic vector

Indexing matrices

x <- matrix(c("a", "b", "c", "d", "e", "f"), nrow=2)
x
     [,1] [,2] [,3]
[1,] "a"  "c"  "e" 
[2,] "b"  "d"  "f"

Uses and limitations of matrices

  • Correspond to the matrices we know and love from linear algebra
  • Usually the right way to store 2-d data for doing math (like matrix multiplication)
  • Like atomic vectors, contain only one type of data
x <- matrix(c(1, 2, 3, 'a', 5, 6), nrow=2)
x
     [,1] [,2] [,3]
[1,] "1"  "3"  "5" 
[2,] "2"  "a"  "6"

Data frames

example_df <- data.frame(x = c(1, 2, 3),
                         y = c('a', 'b', 'c'))
example_df
  x y
1 1 a
2 2 b
3 3 c

Aside: what are data frames?

example_df <- data.frame(x = c(1, 2, 3),
                         y = c('a', 'b', 'c'))
typeof(example_df)
[1] "list"
  • Matrices are like a 2-d atomic vector
  • Data frames are a special type of list! With some requirements:
    • Each component is a vector
    • Each component has the same length

Indexing data frames

[ ] can work for indexing data frames, just like matrices:

example_df <- data.frame(x = c(1, 2, 3),
                         y = c('a', 'b', 'c'))
example_df
  x y
1 1 a
2 2 b
3 3 c
example_df[2, 1]
[1] 2

Indexing data frames

Like lists, [[ ]] and $ can also be used:

example_df <- data.frame(x = c(1, 2, 3),
                         y = c('a', 'b', 'c'))
example_df
  x y
1 1 a
2 2 b
3 3 c
example_df$x
[1] 1 2 3
example_df[["x"]]
[1] 1 2 3
