Series

Recall that in R, a data.frame is a collection of atomic vectors. In pandas, a DataFrame is a collection of Series.

What is a Series? A Series is a one-dimensional object for storing data. E.g.:

import pandas as pd

s1 = pd.Series([1.0, 2.0, 3.0])
s1
0    1.0
1    2.0
2    3.0
dtype: float64

In many respects a Series behaves like an R vector.

For example, we can compute statistics like the sum or the mean:

s1.sum()
np.float64(6.0)
s1.mean()
np.float64(2.0)

We can do arithmetic with a Series, which will update each entry:

s1 + 1
0    2.0
1    3.0
2    4.0
dtype: float64
s1**2 #(squaring)
0    1.0
1    4.0
2    9.0
dtype: float64

Note that not all mathematical operations are built into base Python or pandas; for those operations, we will need to load an additional package, usually NumPy. For example, to take a square root:

import numpy as np

np.sqrt(s1)
0    1.000000
1    1.414214
2    1.732051
dtype: float64

And we can do arithmetic with multiple Series:

s1 = pd.Series([1.0, 2.0, 3.0])
s2 = pd.Series([4.0, 5.0, 6.0])

s1 + s2
0    5.0
1    7.0
2    9.0
dtype: float64
s1 * s2
0     4.0
1    10.0
2    18.0
dtype: float64

Indexes

We said that a Series behaves, in some ways, like an atomic vector in R. However, there are some important differences.

One key difference is that a Series always has an Index – this is like a label for each entry in the Series. The Index can be specified when creating the Series:

s1 = pd.Series([1, 2, 3], index = ['a', 'b', 'c'])
s1
a    1
b    2
c    3
dtype: int64

Important: The a, b, c that is printed on the left is not another column in the Series. Rather, this is the Index!

If we don’t specify an index, pandas will default to a range index starting at 0:

s2 = pd.Series(["hello", "world"])
s2
0    hello
1    world
dtype: object

Choosing entries with the Index

The Index can be used to choose entries from the Series:

s1['a']
np.int64(1)
s1[['a', 'b']]
a    1
b    2
dtype: int64

Notes:

  • If a single entry is selected, we reduce the dimensionality of the resulting object. That is, s1['a'] returns a single number (the integer 1), rather than a Series
  • To select multiple entries, we usually need to include them in a Python list. That is: s1[['a', 'b']] will work, but s1['a', 'b'] will not!

Positional indexing

Indexes in pandas often feel weird to R users, because we usually don’t have row names for our vectors or data frames (it is sometimes possible, but it is not common). In R, we are instead used to indexing our vectors by position.

Fortunately, using .iloc we can index a Series by position too!

s1 = pd.Series([11, 23, 35], index = ['a', 'b', 'c'])
s1.iloc[0]
np.int64(11)
s1.iloc[1]
np.int64(23)
s1.iloc[1:2] # right endpoint is not inlcuded!
b    23
dtype: int64
s1.iloc[1:3]
b    23
c    35
dtype: int64

Notes:

  • In Python, positional indexing begins at 0!! (whereas in R, it begins at 1)
  • In R, doing 1:3 will include both endpoints in the slice. In Python, the left endpoint will be included, but the right endpoint will not

DataFrame

A DataFrame in pandas is just a collection of Series:

s1 = pd.Series([1.0, 2.0, 3.0])
s2 = pd.Series([4.0, 5.0, 6.0])

df1 = pd.DataFrame({"x": s1, "y": s2})
df1
x y
0 1.0 4.0
1 2.0 5.0
2 3.0 6.0

Like a Series, a DataFrame has an index, which labels the rows:

s1 = pd.Series([1.0, 2.0, 3.0], index = ['a', 'b', 'c'])
s2 = pd.Series([4.0, 5.0, 6.0], index = ['a', 'b', 'c'])

df1 = pd.DataFrame({"x": s1, "y": s2})
df1
x y
a 1.0 4.0
b 2.0 5.0
c 3.0 6.0
