Wrangling with exam grades

You work in the Office of Institutional Research at a large university, and your boss asks you to investigate the relationship between student evaluations and scores on the final exam in introductory statistics courses.

We have two CSV files to investigate this question. The exam_grades.csv file contains last semester’s final exam scores for 800 students taking introductory statistics across 30 different sections. The columns include:

  • student_id: a unique 4-digit identifier for each student
  • classid: which of the 30 sections the student was enrolled in
  • professor_name: the name of the professor which whom the student took the class. Each professor teaches several sections
  • exam_score: the student’s score on the final exam. All introductory students take the same final exam, regardless of course section

Your boss also provides you with information on each professor’s course evaluations. The professor_evals.csv file contains evaluations for each of the 10 professors teaching introductory statistics. The classid_1, classid_2, and classid_3 columns identify the 3 sections taught by each professor, while the three evalscore columns contain the professor’s corresponding course evaluation scores (out of 5) for each class.

You can import the data with

import pandas as pd

Weight class?

We want to merge the ufc_athletes and the ufc_fights datasets together. One column that will help us merge is the weight_class column, which appears in each dataset.

However, we need to check that weight_class is recorded in the same way for each table!

TipQuestion

Cleaning weight class

To make the weight classes match between the two data frames, we need to clean the entries in the ufc_fights data. Carrying out all the necessary cleaning steps is a bit beyond what we have covered in class so far, so I will provide the code here – but we will discuss some of this material later in the class!

The code below converts the weight classes in the ufc_fights data into values that match the ufc_athletes data, and stores the resulting output in ufc_fights_clean.

import numpy as np
from itertools import chain

# unique weight classes from athletes data (converted to string)
athlete_weights = ufc_athletes['weight_class'].dropna().unique().astype('U')

# separate into an array of key words
# (We will keep only key words from this array in the 
# ufc_fights data)
athlete_weights = np.char.split(athlete_weights)
weight_keywords = np.unique(list(chain.from_iterable(athlete_weights)))

# function to extract just the pieces of weight class that are 
# in the weight_keywords
def filter_words(split_words):
  return ' '.join([s for s in split_words if s in weight_keywords])

# apply the function to the ufc_fights data
ufc_fights_clean = ufc_fights.assign(weight_class = 
  ufc_fights['weight_class'].str.split(' ').apply(filter_words))
