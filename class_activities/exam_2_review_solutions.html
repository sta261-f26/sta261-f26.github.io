Standard deviation

The sample standard deviation of numbers \(x_1,...,x_n\) is given by

\[\widehat{\sigma} = \sqrt{\frac{1}{n-1}\sum \limits_{i=1}^n (x_i - \bar{x})^2},\]

where \(\bar{x} = \frac{1}{n} \sum \limits_{i=1}^n x_i\).

TipQuestion 6

Write a function called my_sd which calculates the standard deviation of a vector in R. Your function should satisfy the following requirements:

Input:

  • x: a vector of the observations \(x_1,...,x_n\)

Output: the estimated standard deviation \(\widehat{\sigma}\)

Error handling: Brainstorm at least two different ways the function could fail if provided with the wrong input. Your function should throw an error (with a helpful message) if those situations occur.

Other requirements: you make not use any existing standard deviation functions (e.g. sd)

Solution:

my_sd <- function(x){
  n <- length(x)
  
  if(n == 1){
    stop("x must have at least 2 elements")
  }
  
  if(!is.numeric(x)){
    stop("x must be a numeric vector")
  }
  
  return(sqrt(1/(n-1) * sum((x - mean(x))^2)))
}

# checking that it works
my_sd(c(1,2,4))
[1] 1.527525
sd(c(1,2,4))
[1] 1.527525

\(\ell_p\) norm

The \(\ell_p\) norm of a vector \(x = (x_1,...,x_k)\) is given by

\[||x||_p = \left( \sum \limits_{i=1}^k |x_i|^p \right)^{1/p}\]

where \(p > 0\).

TipQuestion 7

Write a function called p_norm in R, which satisfies the following requirements.

Input:

  • x: a vector containing \(x_1,...,x_k\)
  • p: the value of \(p\) to use when computing the norm. Make p = 2 the default value (this corresponds to the usual Euclidean norm).

Output: the \(\ell_p\) norm of x

Error handling: Brainstorm at least two different ways the function could fail if provided with the wrong input. Your function should throw an error (with a helpful message) if those situations occur.

Solution:

p_norm <- function(x, p=2){
  if(p <= 0){
    stop("p must be positive")
  }
  
  if(!is.numeric(x)){
    stop("x must be a numeric vector")
  }
  
  (sum(abs(x)^p))^(1/p)
}

p_norm(c(1, 1, 1)) # = sqrt(3)
[1] 1.732051
p_norm(c(1, 2, 3), 1) # = 6
[1] 6

Kurtosis

Suppose we have a sample \(X_1,...,X_n\) from some population distribution. We know that the mean describes the “center” of the distribution, the standard deviation is a measure of variability, and skewness describes the shape of the distribution.

Another quantity we can calculate to describe a distribution is kurtosis, which describes how heavy the tails of the distribution are. The sample kurtosis is calculated by:

\[\dfrac{\frac{1}{n} \sum \limits_{i=1}^n (X_i - \bar{X})^4}{\left( \frac{1}{n} \sum \limits_{i=1}^n (X_i - \bar{X})^2 \right)^2} \ \ - \ \ 3\]

where \(\bar{X}\) is the sample mean.

TipQuestion 8

Write a function in R to calculate the sample kurtosis.

Input:

  • x: a vector containing \(X_1,...,X_n\)

Output: the sample kurtosis for x

Error handling: Brainstorm at least two different ways the function could fail if provided with the wrong input. Your function should throw an error (with a helpful message) if those situations occur.

Solution:

my_kurtosis <- function(x){
  if(length(x) < 2){
    stop("x must have at least 2 elements")
  }
  
  if(!is.numeric(x)){
    stop("x must be a numeric vector")
  }
  mean((x - mean(x))^4)/(mean((x - mean(x))^2))^2 - 3
}

Accuracy

Let \(Y_1,...,Y_n \in \{0, 1\}\) be observations from a binary variable that we are interested in predicting, and let \(\widehat{p}_i = \widehat{P}(Y_i = 1)\) be the estimated probability that \(Y_i = 1\). For example, we may get these estimated probabilities from a logistic regression model.

Since \(\widehat{p}_1,...,\widehat{p}_n \in [0, 1]\), we can convert our predicted probabilities into binary predictions by thresholding:

\(\widehat{Y}_i = \begin{cases} 1 & \widehat{p}_i > h \\ 0 & \widehat{p}_i \leq h \end{cases}\)

where \(h\) is a user-specified threshold. Then, the accuracy of our binary predictions is defined as:

\[\text{Accuracy} = \frac{\#\{\widehat{Y}_i = Y_i\}}{n}\]

where the numerator denotes the number of predictions \(\widehat{Y}_i\) which agree with the true observed response \(Y_i\).

TipQuestion 9

Write a function called calc_accuracy which satisfies the following requirements:

Input:

  • y: the vector of observed responses \(Y_1,...,Y_n\)
  • p: the vector of estimated probabilities \(\widehat{p}_1,...,\widehat{p}_n\)
  • h: the thresholding to use when converting \(\widehat{p}_1,...,\widehat{p}_n\) into binary predictions

Output: the accuracy

Other requirements:

  • Your function should leverage R’s vectorized operations. No loops!

Solution:

calc_accuracy <- function(y, p, h=0.5){
  yhat <- p > h
  sum(y == yhat)/length(y)
}

frac_a <- function(df){

Practice with probability simulations

Three players enter a room and a red or blue hat is placed on each person’s head. The color of each hat is determined by [an independent] coin toss (so, any combination of red and blue hats is possible). No communication of any sort is allowed, except for an initial strategy session before the game begins. Once they have had a chance to look at the other hats [but not their own], the players must simultaneously guess the color of their own hats or pass. The players win the game if at least one person guesses correctly, and no one guesses incorrectly.

TipQuestion 13

Here is one strategy: one player randomly guesses the color of their hat, while the other two players pass. Write a simulation to estimate the probability the players win the game (the true probability is 1/2).

Solution:

set.seed(91)

nsim <- 1000
results <- rep(NA, nsim)
for(i in 1:nsim){
  hats <- sample(c("red", "blue"), 3, replace=T)
  guesses <- c(sample(c("red", "blue"), 1), "pass", "pass")
  results[i] <- guesses[1] == hats[1]
}

mean(results)
[1] 0.48
TipQuestion 14

Here is another strategy: if a player sees the same color on the other two hats, they guess the color they do not see. If a player sees different colors on the other two hats, they pass. For example: If players A, B, and C have hats red, blue, and blue respectively, then player A would guess red, player B would pass, and player C would pass. Write a simulation to estimate the probability the players win the game with this new strategy (the true probability is 3/4).

Solution:

nsim <- 1000
results <- rep(NA, nsim)
for(i in 1:nsim){
  hats <- sample(c("red", "blue"), 3, replace=T)
  guesses <- rep(NA, 3)
  for(j in 1:3){
    other_hats = hats[-j]
    num_other_colors = length(unique(other_hats))
    if(num_other_colors == 1){
      guesses[j] <- ifelse(other_hats[1] == "red", "blue", "red")
    } else {
      guesses[j] <- "pass"
    }
  }
  
  results[i] <- sum(guesses[guesses != "pass"] == hats[guesses != "pass"]) == 
    length(guesses[guesses != "pass"])
}

mean(results)
[1] 0.751
