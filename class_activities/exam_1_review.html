What you should know

Data wrangling

You are expected to be familiar with the main ways we have discussed manipulating data:

  • Subsetting rows or columns
  • Grouping and summarizing
  • Combining datasets (merging/joining; difference between left and inner joins)
  • Reshaping data (pivoting)

This means that you will need to be familiar with some of the key data wrangling functions that we have used from the tidyverse and from pandas.

Functions to know from R

  • mutate
  • select
  • filter
  • count
  • group_by
  • summarize
  • inner_join
  • left_join
  • pivot_longer
  • pivot_wider
  • Within pivot_longer, you should also be familiar with passing multiple column names to names_to, and the use of .value
  • You should know the names of basic summary statistic functions: mean, median, min, max, sd
  • When calculating summary statistics (means, medians, standard deviations, etc.) you should know that missing values need to be ignored (na.rm = T in many functions) unless we want the result to be NA

Functions to know from pandas

  • assign
  • groupby
  • agg
  • merge
  • melt
  • wide_to_long
  • pivot
  • You should know that by default, pandas functions for computing summary statistics will skip missing values (unlike R!)
  • You should know the names of basic summary statistic functions: mean, median, min, max, std, count

How well do I need to know the functions?

  • You are expected to know which function to use in order to accomplish a specific task. For example: if you are asked to reshape data, and your answer uses pivot_wider when you should have used pivot_longer, you will lose points.

  • You are expected to be able to identify the order in which functions should be applied (which will depend on the specific problem).

  • You are expected to know the effect of these functions on data. E.g., mutate adds or modifies a column; summarize will produce one row of summary statistics for each group; the differences between pivot_longer and pivot_wider; etc.

  • You should roughly know the arguments that each function takes. For example, pivoting requires me to specify which columns to pivot, and what to do with names and values. However, you do not need to know the exact argument names. E.g., if you write names and values instead of names_to and values_to, I would not deduct any points.

  • I will not harshly penalize syntax mistakes. Some examples (not exhaustive):

    • In pandas, you can create a named summary statistic in agg with something like .agg(mean_length = ('bill_length', 'mean')). If you instead wrote .agg(mean_length = mean(bill_length)), you would get most of the points for that problem
    • In pandas, when you want to pass multiple variable names in a function argument, you often need to pass it as a list. E.g., pd.wide_to_long(..., i = ['RID', 'GroupAssignment'],...). If you instead wrote i = 'RID', 'GroupAssignment', I would not deduct points
    • If you write groupby instead of group_by (or vice versa), I don’t care. You clearly know what function you want to use!

What about other functions we have seen?

There are lots of other functions we have used on the homework and class activities (examples include fct_collapse, case_when, drop_na, reset_index, all of the plotting functions, etc.). I will not test you on these additional functions.

This doesn’t mean that those functions aren’t important! Just that there is a limit to what I can reasonably expect you to memorize for a written exam, and I want you to focus on the core functions that implement the big data wrangling ideas (grouping, summarizing, mutating, reshaping, joining).

Data structures and indexing

You are expected to be familiar with some of the basic structures that we have worked with in R and pandas.

In R

The data structures to know include:

  • vectors
  • lists
  • data frames

You should be able to:

  • extract elements from a vector using []
  • extract elements from a list using [] and [[]]
  • create a list containing desired elements
  • explain the relationship between a data frame and a list
  • You do not need to know the code for creating a data frame from scratch

In Python

The data structures to know include:

  • pandas Series
  • pandas DataFrames

You should be able to:

  • explain the difference between choosing elements by index label vs. choosing elements by position
  • extract elements from a Series using the index
  • extract elements from a Series using position ( with .iloc)
  • understand that different pandas functions interact with the index in different ways. However, you are not expected to memorize these different behaviors
  • You do not need to know the code for creating a data frame or Series from scratch

  • Find real datasets online, and think about how you would analyze them. The TidyTuesday datasets are a really good source of real, messy data. (Just ignore any datasets that are focused mostly on text data, since we don’t know how to work with text data or strings yet!)

High rainfall during summer 2025 caused concern about the water quality of beaches in Sydney, Australia.

To explore the relationship between rainfall and water quality, we have measurements on both water quality and weather data from 1991 to 2025.
