How likely is ‘likely’? Revisited

Motivation

In an online quiz, created as an independent project by Adam Kucharski, over 5,000 participants compared pairs of probability phrases (e.g. “Which conveys a higher probability: Likely or Probable?”) and assigned numerical values (0–100%) to each of 19 phrases. The resulting data can be used to analyse how people interpret common probability phrases.

Data

The code below will download three different datasets:

import pandas as pd

absolute_judgements = pd.read_csv('https://raw.githubusercontent.com/rfordatascience/tidytuesday/main/data/2026/2026-03-10/absolute_judgements.csv')
pairwise_comparisons = pd.read_csv('https://raw.githubusercontent.com/rfordatascience/tidytuesday/main/data/2026/2026-03-10/pairwise_comparisons.csv')
respondent_metadata = pd.read_csv('https://raw.githubusercontent.com/rfordatascience/tidytuesday/main/data/2026/2026-03-10/respondent_metadata.csv')

absolute_judgements.csv

In the absolute_judgements dataset, respondents provide a numerical value (0-100%) for each different probability phrase (“Little Change”, “Almost No Chance”, etc.). These 19 different phrases were presented to each respondent in a random order.

variable class description
response_id integer Unique respondent identifier.
term character Probability phrase.
probability integer Numerical estimate (0–100).
order integer Presentation order of this term for the respondent.

pairwise_comparisons.csv

In the pairwise_comparisons dataset, respondents were presented with pairs of probability phrases, and asked to decide which phrase indicated higher probability.

variable class description
response_id integer Unique respondent identifier.
pair_id integer Pair sequence number within the respondent’s session (1–10).
term1 character First term shown.
term2 character Second term shown.
selected character The term the respondent chose as higher probability.

respondent_metadata.csv

The respondent_metadata dataset contains some information on respondent demographics.

variable class description
response_id integer Unique respondent identifier.
timestamp character Submission month (YYYY-MM).
age_band character Self-reported age band (e.g. “25-34”).
english_background character English language background.
education_level character Highest education level.
country_of_residence character Country of residence.

Solution:

  .agg({'term': 'nunique'})
  .agg({'term': ['min', 'max']}))

Joining datasets

Read the introduction to the merge method in pandas. Then answer the following question.

  1. Merge the absolute_judgements and response_metadata datasets, and use the resulting dataset to compute the average probability for each age band. Which age band is most “optimistic”?

Solution:

merged_data = absolute_judgements.merge(respondent_metadata, how = 'left', on = ['response_id'])

# which age band is most optimistic?
(merged_data.groupby(['age_band'])
  .agg({'probability': ['mean', 'std']})
  .sort_values(('probability', 'mean'), ascending = False))
